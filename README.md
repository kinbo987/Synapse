# Synapse
---
Synapse是一款能实现文件传输/剪切板同步等功能的轻量化应用(肯定不是被微信传输助手逼急了
两电脑同时开微信/QQ会顶号？微信\QQ文件传输会限速?电脑之间传输文件很麻烦？
想打造笔记本+台式办公空间？Windows查看不了蓝牙耳机的具体信息?
不妨试试........Synapse！！！
---
tips:蓝牙耳机电量查询(左耳/右耳/耳机盒)目前仅支持华为耳机(如果你不是华为耳机也能用,那恭喜你,你中奖了)
目前进度:电脑端v1.1开发  手机端v0.0开发
(此版本为测试方便只有单exe文件,启动时会多一步解包,可能会有启动时间较长的问题)

手机端v0.0
电脑端v2.0:
1. 远程传输: 远程p2p传输文件和剪切板
2. 自带额外功能:  自带文件查看,压缩/解压缩功能,此功能通过集成其他开源项目实现
3. 传输完成后自动执行脚本:  允许用户为每个接收设备配置后处理脚本(如解压)
电脑端v1.1:
1. 优化传输:  对大于n GB的文件使用先压缩再传输再解压的方式传输,n可以在设置中调整,n可以是小数
用户配置：提供 N GB 的阈值设置,用户可在设置中关闭*优化传输*(默认开启)
智能检测：在传输前检测文件类型，对已压缩文件会跳过压缩直接传输
采样决策：对可压缩文件进行头部采样，若压缩率超过阈值则进行压缩，否则直接传输
分块传输：对确认要压缩的大文件，采用分块压缩传输
2. 定时传输:  支持定时传输，让用户安排在网络空闲时段进行大文件传输
3. 加密配对:  
4. 多设备传输:  可以选择任意个设备进行传输
---
电脑端v1.0:
1. 历史记录:  剪切板和传文件的历史记录,在本地保留文本/图片历史（可设置条目数）,能回溯之前复制的内容
2. 外接设备扩展:  耳机等蓝牙设备的电量显示和提醒
3. 设置:  添加设置页面
4. 拖拽发送:  将文件或文件夹从系统资源管理器直接拖入窗口，自动识别并排队发送
5. 传输管理:  允许多个传输任务排队，支持调整顺序、暂停/恢复/取消单个任务，显示总进度和剩余时间
6. 限速设置:  在设置中提供上传/下载速度限制,可以设置输入的单位(设置两档:GB,MB),在每个传输任务下方可选择本传输任务是否开启限速
7. 设置优化: 在设置下方添加保存设置按钮,在设置保存成功时提示用户
8.  接收策略:  用户可选择“自动保存到下载目录”或“每次询问保存位置”,用户可选择下载目录(默认:电脑端:"C:\Users\用户名\Downloads");
9.  主题切换:  提供暗/亮色选项和自动跟随系统主题,可在设置中切换;
10. 传输完成通知
11. 网络质量检测:  显示当前 WiFi 信号强度、延迟、丢包率;



电脑端v0.0:
1. 快速传文件：文件传输不限大小、不限速;
2. 共享剪贴板：文本/图片跨设备双向同步;
3. 断点续传：断网后重连自动从断点继续;
4. 设备信息查看:  电量/IP等信息查看;
